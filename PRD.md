Product Requirements Document (PRD)
Date: August 02, 2025
1. Overview
This document outlines the product requirements for a Catholic Church Parish App intended for
local, diocesan, national, and international deployment. The app is owned by one parish but
designed for scalability.
2. User Registration and Login
- Centralized database for all users.
- Registration requires: Baptismal Name/Full Name, Parish (dropdown from approved list), Email,
Password, Sex, Church Group, Birthday Month.
- If Parish not listed, user can either wait or register without parish (limited features).
- Registered users automatically get access to their Parish homepage and selected group page.
- Certain features are locked unless the parish is approved.
- Persistent login: User stays authenticated across sessions.
3. Church Groups
Groups during registration:
- CMO (Catholic Men Organization)
- CWO (Catholic Women Organization)
- CYON (Catholic Youth Organization of Nigeria)
- HCA (Holy Childhood Association)
Secured groups inside the app (require admin approval):
- Harvest Committee
- Parish Finance Committee
- Laity Council
4. App Navigation
The app contains 4 main pages:
1. Home
2. Groups
3. Finance
4. Profile
5. Home Page
- Brief History of the Parish
- Announcements (e.g. Sunday Mass time, Readers)
- Bible Study section
- Advertisements
6. Groups Page
- Displays user's registered group with info and updates.
- Optional secure groups shown at bottom, accessible with admin approval.
- Group pages are read-only; users receive updates from group admins.
7. Finance Page
- Track My Donations
- View Pledges Made
- View Pledges Paid
8. Profile Page
- Shows user's personal and church-related information.
- App settings and preferences.
- Option to request transition between groups (e.g. CYON to CMO/CWO upon marriage).
